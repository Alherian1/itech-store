# iTech — Equipos Ensamblados Premium

Sitio web de una tienda de computadoras ensambladas a pedido. Desarrollado como proyecto escolar con enfoque en diseño frontend moderno, interfaz oscura y experiencia de usuario fluida.

## ¿Qué es iTech?

iTech es una tienda en línea que ofrece PCs gaming, workstations y equipos profesionales ensamblados con componentes seleccionados. El sitio está diseñado para que el usuario pueda explorar el catálogo, ver detalles de cada equipo y agregar productos a un carrito de compras, todo sin recargar la página.

## Tecnologías

- HTML5
- CSS3 personalizado + Tailwind CSS (CDN)
- JavaScript vanilla
- Font Awesome 6 para iconografía

## Estructura del proyecto

```
itech-store/
├── itech.html        # Página principal
├── css/
│   └── style.css     # Estilos personalizados
├── js/
│   └── main.js       # Lógica del carrito, modales y búsqueda
└── img/
    └── logo.jpg      # Logotipo de la marca
```

## Funcionalidades implementadas

- Navbar responsive con menú móvil y barra de búsqueda
- Hero section con llamadas a la acción
- Catálogo de productos con datos cargados dinámicamente desde JS
- Modal de vista rápida por producto con especificaciones y precio
- Carrito lateral con conteo de items y total en tiempo real
- Botón de agregar al carrito con notificación tipo toast
- Secciones de categorías y ofertas
- Footer con newsletter y redes sociales
- Diseño adaptable a móvil y escritorio

## Estado del proyecto

Proyecto frontend completo en su capa de presentación e interactividad. No cuenta con backend ni base de datos; los productos y la lógica del carrito se manejan en el cliente mediante JavaScript. La integración con un servidor y procesamiento de pagos está fuera del alcance de esta fase.
